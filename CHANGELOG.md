# Changelog

All notable changes, newest first. Versions follow `MAJOR.MINOR.PATCH`; `versionCode` goes up by one every release.

## 1.3.0 (versionCode 4)

UI, UX, art and fun. One pixel-art app (the experimental Cosmos style was dropped).

- Design system: theme tokens, pixel UI kit (buttons, panels, chips, dialogs, progress bars), 20 pixel icons.
- Bottom bar (Brodex, Battle, Catch, Trainer), shared-element card transitions, swipe between cards on a bro's page.
- Catch wizard (5 steps) with auto-saved drafts and a Quick Catch (name only); card completeness nudge.
- Quick actions on long-press, swipe actions on the list with undo, typo-tolerant search and recent searches.
- Toasts, 8-bit sounds (synthesized at runtime, no audio files), haptics; all switchable in Settings.
- Alive art: idle blinking and breathing, type particles, parallax, illustrated Rare/Epic/Legendary frames, a day/night sky, animated splash, skippable evolution cinematic.
- Dexy, the guide mascot. Daily Pack (cosmetics only, no streaks), stickers, card frames, new backdrops and hats, Trainer Room, group photos, a hidden secret frame.
- Settings: Sound & feel switches, Report a bug / Suggest a feature email, What's new.
- Accessibility: reduce motion everywhere, 48 dp touch targets, type icons next to names, TalkBack card summaries.
- Database schema v7 (`cardFrame`, `stickers`) with an automatic migration; migration tests added.
